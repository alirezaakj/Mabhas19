# Planned Android application root

Open this folder in Android Studio **after Phase 1 creates the Gradle project**. At present this is a planning placeholder; there is no buildable APK, wrapper or test task.

See [architecture and module structure](../docs/android/architecture.md), [implementation sequence](../docs/android/implementation-plan.md), and [test strategy](../docs/android/testing.md).

First scaffold should introduce only the app and core modules needed for project creation and the air-test vertical slice. Keep application ID/minimum SDK provisional until owner decisions are recorded. All dependency versions must be pinned as a compatible set.
